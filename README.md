🚀 Getting Started

1. Clone the repository

git clone https://github.com/Anshulupadhyay61/My-Portfolio.git
cd My-Portfolio

2. Install dependencies

npm install

3. Start the development server

npm run dev

Vite will provide the local development URL in the terminal.

4. Create a production build

npm run build

5. Preview the production build

npm run preview

📱 Responsive Design

The portfolio is designed to provide a consistent experience across desktop, laptop, tablet, and mobile screens.

The interface adapts its layout, spacing, typography, and interactive elements according to screen size.
